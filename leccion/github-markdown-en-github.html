Markdown en GitHub - README, issues y comentarios que se leen bien

Todo lo que escribes en GitHub - README, issues, pull requests, comentarios - usa Markdown. Títulos, listas, listas de tareas, tablas, bloques de código con colores, enlaces a archivos, menciones, referencias a issues y commits, avisos destacados y la estructura de un README que la gente lee.

▶ Abrir la lección interactiva (3 ejercicios)

Al terminar vas a poder

  • Dar formato con títulos, listas, negrita, enlaces e imágenes
  • Escribir tablas, listas de tareas y bloques de código con lenguaje
  • Referenciar personas, issues, PRs y commits
  • Usar avisos destacados (NOTE, WARNING)
  • Estructurar un README útil
🧠 En palabras simples

Markdown es una forma de dar formato escribiendo símbolos simples: # para un título, - para una lista, ** para negrita. GitHub lo convierte en una página prolija. Es el mismo Markdown de las celdas de JupyterLab, con algunos extras.
